# Nasser Endodontics — Website Redesign

A clean, modern redesign of [nasserendo.com](https://www.nasserendo.com) — the practice website for **Dr. Thomas K. Nasser, DDS**, a board-certified root canal specialist in Carmel, IN.

## About This Project

This project was built using **Claude AI** as a demonstration of what AI can do for small business owners who want to modernize their online presence — without needing a web developer or a big budget.

The original site, managed by a third-party dental web company (PBHS), had dated styling and a cluttered layout. Using only a description of the site's content and design goals, Claude:

- Scraped and extracted all existing text content from the live site
- Redesigned the layout from scratch with a clean, modern aesthetic
- Preserved the blue color theme and all original content
- Produced a single, fully self-contained HTML file — no frameworks, no dependencies, no build step

**The entire redesign took under 5 minutes.**

## What This Demonstrates

This is part of a personal project to show **older entrepreneurs in my family** what's now possible with AI tools. Many small business owners are locked into expensive website management contracts, paying monthly fees for sites that look outdated and are hard to change. AI makes it possible to:

- Redesign a website in minutes, not weeks
- Generate clean, production-ready code without knowing how to code
- Deploy a live site for free using tools like GitHub + Vercel
- Iterate quickly — change colors, copy, layout — just by describing what you want

## Tech Stack

- Pure HTML + CSS (no JavaScript frameworks)
- Inline SVG icons
- Google Fonts (Inter)
- Deployed via [Vercel](https://vercel.com) from this GitHub repo
